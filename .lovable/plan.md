

## Rename "wsf leader" to "Home Cell Leader" in User Management

### Problem
Role labels in User Management are generated by replacing underscores with spaces (`wsf_leader` → `wsf leader`). This needs to display as "Home Cell Leader" instead.

### Solution
Add a `roleLabels` map in `src/pages/UserManagement.jsx` that provides custom display names, and use it wherever roles are displayed as text (4 locations).

### Changes in `src/pages/UserManagement.jsx`

Add a label map near the existing config objects:
```javascript
const roleLabels = {
  super_admin: "Super Admin",
  admin: "Admin",
  unit_leader: "Unit Leader",
  wsf_leader: "Home Cell Leader",
  member: "Member",
};
```

Replace all 4 instances of `r.replace("_", " ")` with `roleLabels[r] || r.replace("_", " ")`:
- Line ~240 (role filter dropdown)
- Line ~315 (role badges in user rows)
- Line ~347 (role toggle labels in edit panel)
- Line ~423 (role select in add-user form)

### Files changed
- **Edit**: `src/pages/UserManagement.jsx`
